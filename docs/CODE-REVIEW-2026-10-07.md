# 整体代码审查与体积精简

2026-10-07。本地 0.2.0 开发版本，对照公开 0.1.2。MB 使用十进制 1,000,000 字节。

## 范围与结果

检查了应用生命周期、普通/长截图、选区、标注、工具栏、原生文字输入、快捷键、权限、复制/保存、资源和构建/打包。未增加网络、依赖或权限。此次修复以下确认问题，不能把代码审查当作全部设备和页面兼容的证明。

| 优先级 | 问题 | 处理 |
| --- | --- | --- |
| P1 | 马赛克中间位图或裁剪失败时，渲染会跳过马赛克而继续导出 | 失败向上传递，整体渲染返回 nil，禁止导出未遮挡图片；增加无效遮挡区域回归测试 |
| P2 | 完成回调参数包含 await，取消可能发生在参数等待期间，已取出的完成回调仍可能执行 | 等待结果后再检查取消，取回调并清空，一次性交付；测试重复完成、取消后晚到结果 |
| P2 | 每个采集回调创建一个主线程 Task，进入 8 帧缓存前仍可能无界积压图片 | 改为有界 AsyncStream 与单个消费者，交付前和处理前均有缓存限制 |
| P2 | 第一帧没有检查面积/高度上限 | 初始视口同样检查，除法避免整数乘法溢出；测试超限几何与无效初始帧 |
| P2 | 兼容模式的最终帧捕获失败或持续移动时，可能无提示地交付缺少末段的图片 | 明确标记部分结果，保留已截内容 |

## 精简

- 删除未使用的滚动条宽度分析、位移校验、工具字符候选、重复图标映射和 consumeSettled 包装。保留 RGB/步幅验证与固定页头分析。
- 复用已经标准化的两帧进行静止/固定页头分析，减少重复转换和内存拷贝。
- Release 显式启用 -Osize 与链接死代码清理；签名前去除调试/本地符号，保留运行时及导出符号。调试符号文件不放入安装包。
- DMG 使用 HFS+ 与最高 zlib 压缩，减少 APFS 容器开销。两种架构分别打包。
- 图标和视觉资源保持一致：Assets.car 1,112,216 字节，AppIcon.icns 62,885 字节。原生系统框架不会打进应用，无第三方运行库。
