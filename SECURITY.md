# Security

Version 0.1.1 is a development preview with no formal security support commitment.

Use [GitHub private vulnerability reporting](https://github.com/xiangyingchang/macshot-simple/security/advisories/new) for security issues. Do not disclose vulnerabilities, screen contents, credentials or personal data in public issues. Include the app/macOS version and a minimal, sanitized reproduction.

The application has no network client entitlement and no upload feature. Sensitive pixel data must not be logged by diagnostics or tests.
