# Contributing

Keep the application focused on selecting, annotating, copying and saving screenshots.
Please discuss additions that require network access, new permissions or external dependencies first.

Use Swift and AppKit. Follow CLAUDE.md for local architecture and validation.
Run `scripts/run-tests.sh` and a Release build with `scripts/build-simple.sh`.
Verify mouse interaction and input methods manually for changes to the canvas.
Keep GPL-3.0 notices and upstream attribution.
